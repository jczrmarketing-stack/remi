# Instrucción para los proyectos de Claude en el escritorio

Pega esto en el `CLAUDE.md` (o las instrucciones del proyecto) de cualquier proyecto propio en
Claude, para que sus decisiones lleguen a Hoy y a la ficha del cliente en el panel de Remi.

```
Al decidir algo de este proyecto (una fecha, un alcance, un monto, posponer una fase), guárdalo
con la herramienta `guardar` del MCP de memoria de Remi, con `tipo: "decision"` y el `tema` de
este proyecto (el mismo nombre con que Remi lo conoce).
```
